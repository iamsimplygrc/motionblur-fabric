Motion Blur is a client-side Fabric mod that adds a smooth motion blur effect to Minecraft.
Powered by the Satin API, this mod applies a configurable shader-based blur to create a more cinematic or fast-paced PvP look.
Works with most clients and shader packs — no OptiFine required.

🔥 Fancy / PvP-Style

Want that clean, smooth motion blur like in PvP clients (Lunar, Feather, Badlion)?
This Fabric mod brings the same effect directly to vanilla Minecraft.
Powered by Satin’s shader pipeline, it’s lightweight, fully client-side, and customizable. Perfect for videos, PvP, or just a more cinematic experience.
